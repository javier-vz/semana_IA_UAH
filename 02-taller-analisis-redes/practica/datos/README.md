# Datos para la práctica

Los CSV de este directorio representan una **red ficticia** exclusivamente pedagógica. Son útiles para verificar el conversor GEXF y practicar en Gephi Lite, sin exponer datos reales.

- `ejemplo_nodos.csv`: identificador único (`id`), nombre mostrado (`label`) y agrupación ficticia (`grupo`).
- `ejemplo_aristas.csv`: `source`, `target`, `tipo`, `peso`.

Cuando se incorpore el fragmento de *Martín Rivas*, incluir una nota de procedencia, un criterio de codificación, la edición consultada y las evidencias de cada relación. Los datos de investigaciones con participantes deberán revisarse antes de publicarse.
