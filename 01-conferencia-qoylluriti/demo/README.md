**Rutas y materiales de campo:** https://github.com/javier-vz/rutas_qoyllurity

## Demostración sugerida

1. Presentar una relación simple entre un lugar, una práctica y una fuente.
2. Seguir sus conexiones en el explorador, mostrando cómo aparecen otros elementos vinculados.
3. Contrastar la visualización con las evidencias que sustentan cada vínculo.
4. Discutir una decisión de representación: por ejemplo, cómo denominar una entidad o cuándo distinguir dos prácticas.

**Preparación:** probar la aplicación y disponer de capturas estáticas como respaldo por si falla la conexión durante el evento. Los materiales de campo se compartirán de acuerdo con sus autorizaciones y condiciones de uso.
